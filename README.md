# 东方五律战记 · Touhou: Fivefold Dominion

一款将 **东方 Project（Touhou Project）** 幻想乡世界观与 **《魔法门之英雄无敌 IV》（Heroes of Might and Magic IV）** 经典战术战棋系统深度同构融合的纯前端像素战棋游戏。

## 核心特色

- **五律阵营魔法轮与英雄亲征**：完整还原生命（信仰圣域）、秩序（幻月庭园）、混沌（魔导结社）、死亡（幽冥公馆）、自然与力量圆心关系轮；博丽灵梦、雾雨魔理沙、八意永琳、蕾米莉亚等英雄亲身上阵与军团并肩作战。
- **原汁原味的 HoMM4 战术核心**：斜 45° 尖顶六边形高地/视线/四阶远程衰减战场、两阶段同时反击、先攻/破先攻、远程反击前卫替伤、四种多格碰撞体积（`1×1` / `1×2` / `2×1` / `2×2`）、全 142+ 战斗与大地图法术体系、36 项技能树与 48 个双修进阶职业。
- **东方幻想乡融合机制**：符卡宣言与符卡收取 Bonus、远程/弹幕擦弹（触发 25% 减伤并反哺灵力与符卡充能）、火力 P 点系统与多阵营专属兵种特技。
- **100% 纯代码像素美术与音效**：基于 PixiJS 的新一代 `64×72` 纯代码高清像素骨骼动画与粒子特效管线（零外部图片依赖）+ Web Audio API 物理建模声学合成引擎。

## 技术栈

- **框架**：TypeScript 5 + Vue 3 + Pinia + Tailwind CSS v4
- **渲染**：PixiJS 8 + `pixelfx` 双缓冲像素特效引擎
- **构建与测试**：Vite 6 + Vitest

## 快速开始

```bash
# 安装依赖
pnpm install

# 启动本地开发服务器
pnpm dev

# 运行全套核心引擎与音效单元测试
pnpm test

# 执行 TypeScript 类型校验与生产构建
pnpm build
```
